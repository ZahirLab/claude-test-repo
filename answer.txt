After entering a URL, browser start searching for the ip address corresponded to the URL on DNS. If URL is valid then it will get the IP address and locate the server for this IP. Then it will send request to that server and if the server has permission, it will sent the requested content back to the browser and the browser will show them.
E2
HTTP - Hypertext transfer protocol, HTTPS - Hypertext transfer protocol secure. If I communicate with server using HTTP, other people like hackers can tap into my communication and can see everything without any encryption.
If I use HTTPS, hacker can still tap into my communication but they will not understand as the communication will be encrypted.
